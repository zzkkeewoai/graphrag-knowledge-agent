## 第 0 步：确认没有旧服务占着端口

```powershell
Get-NetTCPConnection -LocalPort 8000 -State Listen
```

**有输出就说明旧服务还在**，先关掉那个窗口（或 `Stop-Process -Id <PID>`）。
不关的话新服务会 `exit 1`，而你会对着旧代码测半天——这个坑今天踩过一次。

## 10 个可以自己试的问题

按难度递增，你可以观察它答得对不对：

| # | 问题 | 期望 |
|---|---|---|
| 1 | 年度股东会应当在上一会计年度结束后的多久内举行？ | 六个月 |
| 2 | 单笔担保额超过净资产多少须经股东会审批？ | 10% |
| 3 | 董事会收到股东提议后多久内要书面反馈？ | 十日 |
| 4 | 募集资金到位后多久内要签三方监管协议？ | 一个月 |
| 5 | 改变募集资金用途要经过哪些程序？ | 董事会决议 + 保荐意见 + 股东会（跨条） |
| 6 | 公司为控股股东提供担保要走什么程序？ | 股东会 + 关联股东回避（**跨文档**） |
| 7 | A 股和 H 股的定期报告分别包括哪些？ | 三季报 vs 五类（**跨文档**） |
| 8 | 中英文文本歧义时以哪个为准？ | 中文 |
| 9 | 公司 2025 年净利润是多少？ | **应拒答**（制度里没有） |
| 10 | 公司现任董事长叫什么名字？ | **应拒答**（只写职务不写人名） |

**第 9、10 题最重要**——它们测的是"不知道会不会编"。如果它开始讲"根据公开信息……"，那就是幻觉，要记下来。

---

## 怎么判断"答得好不好"

| 看什么 | 好的样子 | 不好的样子 |
|---|---|---|
| 有没有引条号 | 「依据《对外担保管理制度》第十五条」 | 只给结论，说不出出处 |
| 数字对不对 | 50% / 70% / 10% 精确 | 含糊说"一定比例" |
| 不知道时 | 「知识库中没有相关规定」 | 用常识补一段 |
| 多跳题 | 把两份文件的结论都说到 | 只答一半 |

## 出问题时的排查顺序

```
① 服务没起来？        → 看第 1 步的窗口有没有报错；确认端口没被占
② 全部答"知识库中没有" → 语料可能没灌（当前应该是 338 块）
                         python -c "import numpy as np; print(np.load('data/local_vectors/document_chunks.npy').shape)"
③ 答非所问            → 看 trace 里的 route 是不是 global
                         python tests/ask_simco.py --q "问题" --trace
④ 召回不到            → python tests/debug_retrieval.py "问题" --top 8 --contains 关键词
⑤ 模型加载报 SSL      → $env:HF_HUB_OFFLINE = "1"（run_api.ps1 已默认设置）
```
