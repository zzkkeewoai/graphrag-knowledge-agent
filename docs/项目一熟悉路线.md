# 站 3：走一遍主链路（20 分钟，只看 6 个地方）

**按数据流读，不要按目录读。**

| 顺序 | 文件 | 只看这个 | 你会发现 |

# 站 4：亲手复现一个实验（15 分钟）

**选一个做**（推荐第一个，因为它能自己跑出数字）。

## 实验 A：检索层 A/B（BM25 到底有没有用）

```powershell
python tests/ab_retrieval.py --top 8
python tests/ab_retrieval.py --top 3
```

**该看到**：
```
top 8：关 46/46，开 46/46        ← 天花板，看不出差别
top 3：关 45/46，开 46/46        ← BM25 救回 1 题
```

**这一步要记住的一句话**：
> 「BM25 在这套语料上收益很小，价值在精确术语的鲁棒性。」

## 实验 B：证据阈值扫描（口语为什么掉 19 个点）

```powershell
# 分别用不同阈值起服务，跑口语集，对比
$env:EVIDENCE_MIN_SCORE='0.55'; # 重启服务后
python tests/run_eval.py --file datasets/weijin48_kouyu.jsonl --out runs/t55.json
# 再改 0.45 / 0.40 重复
```

**该看到**：0.55 → 约 81%，0.45 → 92%，0.40 → 98%，而无关问题（0.32）始终被拒。

**这一步要记住的一句话**：
> 「阈值必须按提问分布标定，换语料要重跑。」
