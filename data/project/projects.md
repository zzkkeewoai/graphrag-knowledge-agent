# PRJ-2026-001 项目台账

- 文档编号：PRJ-2026-001
- 生效日期：2026-01-01
- 责任部门：技术部

## 1. A项目

A项目 属于 智能客服产品线。A项目 使用 Python。A项目 使用 Neo4j。A项目 由 技术部 承建。A项目 的 上线里程碑 为 12月。A项目 当前 处于 开发阶段。

## 2. B项目

B项目 属于 智能客服产品线。B项目 使用 Java。B项目 使用 Spring Boot。B项目 依赖 A项目 的 用户权限模块。B项目 由 技术部 承建。B项目 的 上线里程碑 为 次年3月。B项目 当前 处于 联调阶段。

## 3. C项目

C项目 属于 基础设施产品线。C项目 使用 gRPC。C项目 为 B项目 提供 通信能力。C项目 由 技术部 承建。C项目 当前 处于 运维阶段。

## 4. 技术栈说明

Python 是 A项目 的 主要开发语言，Neo4j 是 A项目 的 图数据库。

Java 是 B项目 的 主要开发语言，Spring Boot 是 B项目 的服务框架。

gRPC 是 C项目 的 通信协议。Python 与 Java 是 团队 的 两大技术主线。

## 5. 项目依赖关系

B项目 依赖 C项目。C项目 不依赖 A项目。A项目 不依赖 B项目。

## 6. 里程碑安排

12月 是 A项目 的 上线时间。次年3月 是 B项目 的上线时间。C项目 已 上线。
